# Информационная система фитнес-клуба

Проект посвящён разработке информационной системы для автоматизации основных процессов фитнес-клуба: работы с клиентами и абонементами, записи на тренировки, учёта посещений и формирования расписания. Система предусматривает возможности для клиентов, администраторов, тренеров и руководителя клуба. Проектная документация включает требования, пользовательские сценарии, архитектуру, UML-диаграммы и тест-кейсы.

## Документация

- `docs/01_project_description.docx` — описание проблемы и назначения системы.
- `docs/02_requirements.docx` — пользователи и функциональные требования.
- `docs/03_scenarios.docx` — нефункциональные требования и пользовательские сценарии.
- `docs/04_architecture.docx` — модель жизненного цикла и архитектура.
- `docs/05_uml_and_tests.docx` — UML-диаграммы и тест-кейсы.

## Основные возможности системы

- Регистрация клиентов и управление абонементами.
- Запись клиентов на тренировки.
- Формирование расписания занятий.
- Учёт посещений фитнес-клуба.
- Управление данными тренеров.
- Формирование отчётов для администрации.

## Пользователи системы

- Клиент — просматривает расписание, записывается на тренировки и управляет абонементом.
- Администратор — оформляет абонементы и управляет расписанием.
- Тренер — просматривает занятия и отмечает посещаемость.
- Директор — просматривает отчёты о работе фитнес-клуба.
